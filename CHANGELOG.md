# Change Log

## 10.0.0

* Updated guides for Angel3 10.0.0 and Dart SDK 3.13 or later
* Updated code samples for `angel3_container_mirrors`, `StaticReflector`, `ioc` with `injection:`, `chain` and `Entity` models
* Updated ORM guides for `postgres` 3.x, MySQL and MariaDB, and relations loaded with a query each
* Updated links to `dart-backend` repositories, and rebuilt the package list
* Added the 10.0.0 migration guide, and guides for running without `dart:mirrors`, HTTP/2, request limits, hooks, caching, Jinja, SEO, Sembast, Kelicap and Podman
* Added the tutorial pages from application setup to deployment, and the CLI commands
* Updated deployment guides for isolates and SSL
* Updated the ORM guides for PostgreSQL 16 or later
* Updated the PostgreSQL sample to match the PostgreSQL ORM template: the executor reconnects when the database restarts, closes at shutdown, and the `POSTGRES_HOST`, `POSTGRES_USERNAME` and `POSTGRES_PASSWORD` environment variables override the configuration
* Updated the dependency snippets of the ORM guides to list `postgres` and `optional`, which the samples import
* Added the MySQL and MariaDB guide to the menu
* Fixed the controllers, ORM basics, migrations and PostgreSQL guides, which showed merge conflict markers
