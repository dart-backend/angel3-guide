This is the documentation site for [Angel3](https://github.com/dart-backend/angel), a Dart backend framework. It contains tutorials and development guides, as well as links to the packages of the Angel3 framework. It covers Angel3 10.0.0, which requires Dart SDK 3.13 or later.

New to Angel3? Read the getting started [Tutorial](https://angel3-docs.dart-backend.com/tutorial/getting-started), and you'll be well on your way. Upgrading from 9.x? Read the [10.0.0 Migration Guide](migration/migration-guide-10.md).
