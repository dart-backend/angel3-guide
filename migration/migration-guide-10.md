# 10.0.0 Migration Guide

Angel3 10.0.0 requires Dart SDK 3.13 or later. Every package is released as 10.0.0, and each lists its breaking changes in its `CHANGELOG.md`, and how to upgrade in the *Migrating from 9.x to 10.0.0* section of its README. This guide covers the changes most apps need.

**WARNING**, commit or back up your code before proceeding with the migration.

## Steps

1. Update the Dart SDK to 3.13 or later, and the constraint in `pubspec.yaml`:

   ```yaml
   environment:
     sdk: '>=3.13.0 <4.0.0'
   ```

2. Change the constraint of every `angel3_*` and `jael3*` package to `^10.0.0`, and run `dart pub upgrade`.
3. If the app uses `MirrorsReflector`, add `angel3_container_mirrors`, and change its import; see [Reflection](#reflection).
4. Regenerate the models of `angel3_serialize` and the ORM:

   ```bash
   dart run build_runner build --delete-conflicting-outputs
   ```

5. Go through the changes below, and those of the README of each package the app uses, and run the tests of the app.

## Reflection

`MirrorsReflector` moved from `package:angel3_container/mirrors.dart` to the new `angel3_container_mirrors` package:

```yaml
dependencies:
  angel3_container_mirrors: ^10.0.0
```

```dart
// 9.x
import 'package:angel3_container/mirrors.dart';

// 10.0.0
import 'package:angel3_container_mirrors/angel3_container_mirrors.dart';

var app = Angel(reflector: MirrorsReflector());
```

`dart:mirrors` is now optional throughout Angel3, including Jael and WebSockets. To compile the app with `dart compile exe`, use a `StaticReflector` generated by `angel3_container_generator`, or no reflector; see [Dependency Injection](../guides/dependency-injection.md#enabling-dart-mirrors-or-other-reflection).

`Container.make` no longer constructs an optional positional parameter whose type is not registered; register the types you want injected.

## Framework

* **`chain`** stops at the first handler that does not return `true`, like the handlers of a route. Return `true` from middleware that only sets a value:

  ```dart
  chain([(req, res) { req.params['user'] = 'me'; return true; }, handler]);
  ```

* **Buffered responses** are sent with a `Content-Length` header instead of chunked transfer encoding. Set `res.chunked = true` to send one chunked.
* **Default response headers**: `AngelHttp.addResponseHeader` and `removeResponseHeader` take a `Map` of headers, and `removeResponseHeader` removes each value of a list, or the header whatever its values for `null`.
* **`bool` ids**: `Service.parseId<bool>` answers ids other than `true` and `false` with a `400 Bad Request`.
* **HTTP/2 sessions** and their cookie are created only when `req.session` is first read.

See [Migrating from 9.x to 10.0.0](https://github.com/dart-backend/angel/tree/master/packages/framework#migrating-from-9x-to-1000) of the framework.

## ORM

* **Relations**: `@HasMany` and `@ManyToMany` are loaded with one query each, after the records, instead of joined. `limit` and `offset` count records, and the query of a `@HasMany` filters and orders its items. See [Relations](../orm/relations.md#loading-relations).
* **Relation keys**: the key of a relation in `QueryValues`, such as `authorId` of a `@BelongsTo AuthorEntity author`, is nullable.
* **`numeric` and `decimal`** columns have no precision and scale unless given; give `precision: 17, scale: 3` to keep those of 9.x.
* **MySQL and MariaDB**: `angel3_orm_mysql` and `angel3_migration_runner` use the [`mysql_dart`](https://pub.dev/packages/mysql_dart) driver, instead of `mysql_client` and `mysql1`. Pass its `MySQLConnection`; see [MySQL and MariaDB](../orm/mysql.md).
* **Migrations** are recorded by `Migration.name`, the class name by default, instead of the source path. The runner renames the records of 9.x on its first run. `defaultsTo` takes a literal; give SQL as a `RawSql`.

## Serialization

* Model classes are named with the `Entity` suffix (`TodoEntity`) in the docs and examples; a `_` prefix still works.
* `Serializable.serializers` is a `List<Serializers>`: replace `0`, `1` and `2` with `Serializers.map`, `Serializers.json` and `Serializers.typescript`.
* `hashObjects` is no longer exported; generated models use `Object.hashAll`.

## Authentication

A JWT expires after a day by default (`jwtLifeSpan`), an expired JWT is revived only within `reviveGracePeriod`, the `token` cookie is `SameSite=Lax`, and a JWT in the query string is ignored unless `allowTokenInQuery` is `true`. See [Authentication](../auth/about.md#security-defaults).

## Other Packages

These packages also have changes that may need changes in an app. Read the *Migrating from 9.x to 10.0.0* section of their READMEs:

| Package | Changes |
| --- | --- |
| [angel3_auth_oauth2](https://pub.dev/packages/angel3_auth_oauth2) | `state` and PKCE in a signed cookie |
| [angel3_auth_twitter](https://github.com/dart-backend/angel/tree/master/packages/auth_twitter) | Redirect flow instead of a PIN |
| [angel3_cache](https://pub.dev/packages/angel3_cache) | Requests with cookies and some responses are not cached |
| [angel3_client](https://pub.dev/packages/angel3_client) | `deserializer` instead of `type`, errors, query lists, broadcast streams |
| [angel3_cors](https://pub.dev/packages/angel3_cors) | `origin: false` disables CORS; only preflights are answered |
| [angel3_file_service](https://pub.dev/packages/angel3_file_service) | Dates stay strings, values are encoded by `json.encode` |
| [angel3_jael](https://pub.dev/packages/angel3_jael), [jael3](https://pub.dev/packages/jael3) | Members read through the reflector, relative paths, `new` removed |
| [angel3_jinja](https://pub.dev/packages/angel3_jinja), [angel3_mustache](https://pub.dev/packages/angel3_mustache) | Views outside the views directory are not found |
| [angel3_mongo](https://pub.dev/packages/angel3_mongo), [angel3_redis](https://pub.dev/packages/angel3_redis), [angel3_rethinkdb](https://pub.dev/packages/angel3_rethinkdb), [angel3_sembast](https://pub.dev/packages/angel3_sembast) | Missing ids are a 404; queries and ids are handled more strictly |
| [angel3_production](https://pub.dev/packages/angel3_production) | Exit code 70 when an instance fails to start |
| [angel3_static](https://pub.dev/packages/angel3_static) | Quoted ETags; symbolic links outside the source are not served |
| [angel3_test](https://pub.dev/packages/angel3_test) | `contentLength`, `service()` takes a `deserializer` |
| [angel3_validate](https://pub.dev/packages/angel3_validate) | Nested validators drop unknown keys |
| [angel3_websocket](https://pub.dev/packages/angel3_websocket) | `@ExposeWs` needs a reflector; broadcast streams; no WebSockets over HTTP/2 |
| [angel3_hot](https://pub.dev/packages/angel3_hot), [angel3_html](https://pub.dev/packages/angel3_html), [angel3_mock_request](https://pub.dev/packages/angel3_mock_request), [angel3_model](https://pub.dev/packages/angel3_model), [angel3_paginate](https://pub.dev/packages/angel3_paginate), [angel3_security](https://pub.dev/packages/angel3_security) | Smaller API changes |
